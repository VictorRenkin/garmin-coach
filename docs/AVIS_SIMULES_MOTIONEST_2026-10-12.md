# Avis simules des 14 sportifs — Motionest

Tous les avis ci-dessous sont generes par MiroFish / OASIS avec le meme modele OpenAI gpt-5.6-sol. Aucun ne provient d un vrai utilisateur ou de Massimo. Les 14 messages initiaux scriptes ne sont pas comptes parmi les 68 commentaires. Chaque commentaire est une reaction a un contexte fourni ; un accord entre agents ne prouve pas un comportement de marche.

La simulation n a pas navigue dans l application. Les controles techniques ont ete executes separement. Les descriptions des personnages sont des fixtures corrigees explicitement pour etre individuelles, pas des biographies reelles.

## Vue d ensemble

14 personnes fictives ; cinq tours ; 70 tours d agents ; 68 commentaires et 39 reactions. Tous les profils ont commente. La participation est imposee pour couvrir les cas, elle ne mesure pas l engagement naturel.
